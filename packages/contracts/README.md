# @membego/contracts

El vocabulario de la plataforma MembeGo: scopes, códigos de error, el sobre de
los eventos y las respuestas de la API v1.

**Cero dependencias.** Ni Prisma, ni Next, ni node: es TypeScript puro, para que
un sistema vertical escrito en cualquier cosa pueda instalarlo sin arrastrar
medio MembeGo detrás.

Es la **fuente**, no una copia: el Core de MembeGo reexporta desde aquí. No hay
dos listas de scopes ni dos tablas de códigos que puedan separarse.

Documentación: `docs/platform/sdk.md`.
